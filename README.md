# Pattern Matching Algorithms — Python Comparison

An academic group project comparing three string-search approaches: **Brute Force**, **Knuth–Morris–Pratt (KMP)**, and **Boyer–Moore**.

## Overview

The Jupyter notebook combines German-language theoretical explanations, Python implementations, and experiments with three input types:

- Repetitive text with a rare search pattern
- Natural-language text with a longer phrase
- DNA sequence with a short nucleotide pattern

The notebook discusses algorithm behavior, time complexity, and practical differences.

## Run

1. Install Python 3 and JupyterLab (`pip install jupyterlab`).
2. Start JupyterLab (`jupyter lab`).
3. Open `pattern_matching_comparison.ipynb` and run the code cells.
